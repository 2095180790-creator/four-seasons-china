## Short description

Four Seasons Across China is an interactive website that presents four seasonal landscapes through photographs and quotations. The homepage offers Spring in Kunming, Summer in Hainan, Autumn in Jiuzhaigou, and Winter in Tibet as image-based entry points. Each page includes a large photograph, an English quotation, and the author's name. The website is built with pure Python, HTML, CSS, and JavaScript. Python uses only the standard library to generate pages, serve static files, and provide a JSON endpoint. The site includes responsive layouts, keyboard navigation, touch gestures, accessibility features, and six automated tests.
